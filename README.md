# OSINT-Operation-The-Paris-Intercept
OSINT Exercise to find the nearest metro station from a given image.
The Scenario
Case File: #FR-75008-DEC
Date: December 3rd, 2023
Time: Approx. 18:00 (Local Time)
Location: Paris, France

Briefing: Investigators have intercepted an image of a masked individual. The subject was photographed in a central, upscale district of Paris. 

Key Intelligence:

Timestamp: Dec 3rd, 2023 @ ~18:00.

Environment: Central, upscale district.

Street Layout: Near the intersection of a "Rue" and an "Avenue."

Objective: Determine the nearest Metro station to this exact standing point.
